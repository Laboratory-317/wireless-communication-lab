# Проверка перед запуском — 21 сентября 2026

Сохраняется страница выбора четырёх оформлений, как согласовано с владельцем.
Сайт собирается для GitHub Pages без пакетов npm и внешних сервисов сборки.
Изменения редизайна пока локальные. Настройки GitHub Pages и успешные деплои текущего `main` подтверждены после авторизации владельца.

## Сделано

- Белые углы исходного логотипа скрыты круглой CSS-обрезкой; знак не перерисован.
- Страница студентов переписана на RU/EN: понятный путь от первого вопроса к исследованию,
  обучение в процессе, приглашение обсудить первую задачу. Кнопка открывает почтовый клиент.
- Исправлены исчезающие абзацы с двоеточиями/URL, отображение Markdown-заголовков,
  фокус после смены языка, размеры переключателей и сохранение пропорций схем.
- Все 37 страниц содержат готовый русский HTML. JavaScript отвечает за RU/EN и выбор
  конкретного CV. Без него на странице CV доступны оба подписанных профиля.
- Добавлены метаданные, значок вкладки, проверка pull request и проверка готового артефакта.
- В сборку попадают только используемые корневые изображения. Логотип синхронизируется автоматически.

## Проверки

- 80 сочетаний тема/язык/страница/профиль: рендер, локальные ссылки, обязательные заглушки.
- 37 готовых HTML: непустой контент без выполнения JS, основной заголовок, метаданные,
  отсутствие повторных ID, ссылки с учётом регистра для Linux, сигнатуры 17 PDF.
- Браузер: 72 страницы на широком экране и 64 при ширине контента 375 px;
  горизонтального переполнения и битых загруженных изображений не найдено.
- Проверены смена языка, сохранение языка в переходах, фокус на выбранном переключателе,
  почтовая ссылка и внешний вид новой студенческой страницы.
- Эти проверки не являются полным аудитом WCAG или проверкой всех библиографических сведений.

## Сверка внешних данных

Исходный автоматический проход по 29 URL сохранён в `link-audit-initial.json`.
403 и ошибки TLS не считаются доказательством отсутствия публикации.

- [РНФ 24-29-00172](https://rscf.ru/project/24-29-00172/): конкурс 2023 года,
  первый этап работ — 2024 год. Период на сайте исправлен на 2024–2025.
- [РНФ 22-79-10148](https://rscf.ru/project/22-79-10148/): добавлена ссылка на карточку.
- [Статья РЭНСИТ](http://rensit.ru/vypuski/article/550/): исправлен DOI русской статьи;
  вместо неработающего DOI-перехода дана страница издателя. HTTPS-сертификат издателя
  просрочен при этой проверке, поэтому используется его рабочий публичный HTTP-адрес.
  Из авторских сведений заполнен рабочий адрес Я. В. Крюкова.
- [Статья о RSMA](https://journals.eco-vector.com/0033-8494/article/view/684125):
  DOI сохранён текстом, переход ведёт на работающую страницу издателя (HTTP 200).
- Старый Google Scholar Д. А. Покаместова возвращает 404 на доменах .ru и .com.
  Поле оставлено для уточнения; добавлен [официальный профиль ТУСУР](https://directory.tusur.ru/people/2554).
- Часть DOI, eLIBRARY и справочник ТУСУР ограничивают автоматические запросы или
  возвращают ошибки TLS. Их доступность для посетителей нельзя гарантировать этим проходом.
