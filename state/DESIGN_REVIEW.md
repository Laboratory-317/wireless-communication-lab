# Четыре оформления сайта лаборатории

Анализ и реализация: 20 сентября 2026 года.

## Вывод по исходному проекту

Существующая архитектура подходит для GitHub Pages: обычный Node.js собирает
Markdown в общую модель данных, а один браузерный рендерер обслуживает все темы.
Отдельные стеки Hugo, Jekyll и Vite не нужны. Исходные названия тем были
стилистическими ориентирами, а не реально используемыми движками.

В четырёх исходных вариантах уже различались шрифты, некоторые сетки, карточки
коллектива и списки. Но доминирующая композиция главной оставалась одинаковой:
большая верхняя шапка, горизонтальное меню и последовательность одинаковых блоков.
Сильнее всего сближались Hugo Academic и Bootstrap Academic.

Документация правильно отделяет контент от кода. Архив `wireless-lab-docs/`
зафиксирован как исторический снимок; актуальные файлы репозитория имеют приоритет.
Папка `themes/` содержит старые самостоятельные макеты и не входит в новую
публикационную сборку. Удалять её для редизайна не требовалось.

Выборка тематическая, а не рейтинг университетов. Проверены первичные сайты,
их структура и десктопное отображение. Часть внешних медиа не загрузилась;
по ним не делались выводы о качестве изображений.

Общий полезный принцип: исследование, люди и проверяемые результаты важнее
декоративных эффектов. Иллюстрация должна помогать понять тему. Известность
коллектива сама по себе не делает все решения его сайта образцом доступности.

Различия сохраняются при мысленном исключении цвета: меняются положение меню,
масштаб изображений, число и соотношение колонок, плотность и типографика.
Существующие адреса страниц и порядок разделов сохранены. На узком экране сетки
переходят в один столбец, боковая навигация становится верхней.

## Контент и иллюстрации

Заполнены описания четырёх направлений и страница для студентов на RU/EN.
Текст основан на существующих проектах, публикациях и CV; новые научные достижения,
условия приёма и обещания финансирования не добавлялись. Незаполненная история
заменена полезной контактной секцией с уже известными сведениями.

Вместо пустых контактов показываются только заполненные; при отсутствии портрета
используются инициалы. Примерная внешняя ссылка в новости заменена переходом
к реальным проектам. Заголовки английской библиографии переведены; оригинальные
названия русскоязычных работ сохранены как библиографические сведения.

Первая серия 3D-изображений создана встроенным imagegen и отклонена пользователем.
В сайт и Git она не включена. Итоговые иллюстрации — небольшие редактируемые SVG
в `assets/research/`: антенная решётка, четырёхбитовое полярное преобразование,
частотно-временная сетка и концептуальная схема RIS. Они не изображают измеренные
характеристики. Подписи и пояснения хранятся в Markdown.

## Поддержка и публикация

Редактор меняет Markdown в GitHub или Obsidian. После изменения `main` GitHub
Actions выполняет проверку и собирает `_site/`. Публикуются только ресурсы сайта,
а не весь репозиторий с инструкциями и архивами. Новые npm-зависимости, внешняя CMS,
платный API и сервер приложений не добавлены.

GitHub Pages поддерживает статические HTML/CSS/JS и собственные сборочные процессы:
[описание Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages),
[сборка через Actions](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages).

Сайт пока использует существующий рендеринг в браузере: для отображения нужен
JavaScript. Это совместимо с Pages, но полноценный HTML-пререндеринг был бы
отдельным улучшением для индексирования и режима без JavaScript. Ради визуального
редизайна модель данных и адреса страниц не мигрировали.

Обновлять тексты и записи можно без программирования. Изменять логику страниц
и создавать новые типы контента по-прежнему должен человек, работающий с кодом;
Markdown не заменяет визуальный конструктор сайтов.

## Что действительно требует исходных данных

Подтверждённая хронология создания лаборатории, отсутствующие фотографии команды
и событий, отсутствующие индивидуальные контакты. Эти сведения не выдуманы,
публичных TODO для них нет. Сайт пригоден для использования без этих материалов.

## Проверка результата

- Автоматически проверены 80 сочетаний тем, языков и страниц, включая оба CV.
- Проверены локальные ссылки, изображения, отсутствие TODO и фиктивных ссылок.
- Отдельно проверены исправления парсера: списки в биографиях не становятся
  контактами, а вступление CV не дублирует все разделы.
- Четыре главные страницы просмотрены на широком экране и в узком iframe.
- Все 32 внутренние страницы в английской версии проверены при ширине контента
  375px: горизонтального переполнения и сломанных загруженных изображений нет.
- Проверены переключение RU/EN, переходы к коллективу и конкретному CV,
  а также работа собранного сайта из подпапки `_site/`.
- Локальная сборка и штатный `tools/codex-check.ps1` прошли. Реальный запуск
  GitHub Actions не проверялся: публикация и push не выполнялись.
