# Проекты

## РНФ

- [Улучшение характеристик систем связи с неортогональным множественным доступом с помощью полярных кодов](https://rscf.ru/project/24-29-00172/). 2024–2025.
- [Перспективные методы множественного доступа для будущих систем беспроводной связи 6G](https://rscf.ru/project/22-79-10148/). 2022–2025.
- [Распределение ресурсов связи в телекоммуникационных системах с неортогональным множественным доступом](https://rscf.ru/project/21-79-00160/). 2021–2023.
- [Использование методов неортогонального множественного доступа для систем беспроводной связи](https://rscf.ru/project/19-79-00087/). 2019–2021.

## Старт

- Разработка широкополосной реконфигурируемой метаповерхности для улучшения беспроводной связи в диапазоне 4,4–5,0 ГГц. 2026–2027.

## Приоритет 2030

- Адаптация полярных кодов к неоднородным каналам передачи. 2026.
- Множественный доступ с разделением по скорости (RSMA). 2024–2026.
- Разработка интеллектуальной отражающей поверхности STAR-RIS для перспективных беспроводных систем связи. 2025.
- Алгоритмы прекодирования общего канала в системах с RSMA. 2024–2025.
- Адаптация полярных кодов к состоянию канала передачи. 2023.
- Имитационное моделирование кодов с малой плотностью проверок на чётность (LDPC) в системах связи 5G NR. 2021–2022.
- Исследование эффективности применения полярных кодов для широкого класса моделей каналов. 2022.
- Экспериментальное исследование неортогонального множественного доступа PD-NOMA для сетей 6G. 2022.
- Разработка экспериментального макета многоканальной системы связи с неортогональным множественным доступом. 2021.
- Концепция и структура программного комплекса для формирования и анализа сигналов 5G NR. 2021.

## Передовая инженерная школа ТУСУР

- Разработка методов и алгоритмов цифровой компенсации искажений в системах беспроводной связи. 2024–2026.
- Разработка модели канала связи с реконфигурируемой интеллектуальной поверхностью. 2023–2025.
- Разработка алгоритмов канального кодирования для систем связи 5G NR. 2023–2025.

## У.М.Н.И.К.

- Разработка интеллектуальной программной системы определения параметров цифровых сигналов на основе методов машинного обучения. 2026–2027.
- Разработка программно-аппаратного комплекса ReCK-RIS для управления реконфигурируемой метаповерхностью. 2026–2027.
- Разработка реконфигурируемой интеллектуальной поверхности. 2024–2025.
- Программное обеспечение для адаптивных LDPC и полярных кодеков. 2022–2024.

## Хозяйственные договоры

- Разработка программного обеспечения и алгоритмов обработки сигналов для радиорелейных модемов «Микрана». 2024.

## Индивидуальные гранты

- Методы формирования и обработки сигналов в многоантенных системах связи с множественным доступом на основе разреженных кодов. 2021–2022.
- Формирование адаптивных к состоянию канала передачи сигнальных конструкций для систем связи с множественным доступом на основе разреженных кодов. 2019–2020.
