# Проекты

## РНФ

- РНФ № 24-29-00172. Улучшение характеристик систем связи с неортогональным множественным доступом с помощью полярных кодов. 2024–2025. [Карточка РНФ](https://rscf.ru/project/24-29-00172/).
- РНФ № 22-79-10148. Перспективные методы множественного доступа для будущих систем беспроводной связи 6G. 2022-2025. [Карточка РНФ](https://rscf.ru/project/22-79-10148/).
- РНФ № 21-79-00160. Распределение ресурсов связи в телекоммуникационных системах с неортогональным множественным доступом. 2021-2023.
- РНФ № 19-79-00087. Использование методов неортогонального множественного доступа для систем беспроводной связи. 2019-2021.

## Старт

- Разработка широкополосной реконфигурируемой метаповерхности для улучшения беспроводной связи в диапазоне 4,4–5,0 ГГц. 2026–2027.

## Приоритет 2030

- Адаптация полярных кодов к неоднородным каналам передачи (2026). Зарегистрировали программу для оптимизации отображения битов кода на физические ресурсы.
- Множественный доступ с разделением по скорости (RSMA, 2024–2026). Разработали имитационную модель с полярными кодами, алгоритмы адаптивного прекодирования и распределения мощности, исследовали работу системы в перегруженном режиме.
- Разработка интеллектуальной отражающей поверхности STAR-RIS для перспективных беспроводных систем связи. 2025.
- Алгоритмы прекодирования общего канала в системах с RSMA (2024–2025). Руководитель НИР — Артём Шинкевич.
- Адаптация полярных кодов к состоянию канала передачи. 2023.
- Имитационное моделирование кодов с малой плотностью проверок на чётность (LDPC) в системах связи 5G NR. В 2021 году по индивидуальному гранту ТУСУРа изучили спецификации 3GPP и описали структуру проверочной матрицы и характеристики кодера. В 2022 году в лабораторном проекте разработали имитационную модель системы связи с LDPC и оценили её помехоустойчивость.
- Исследование эффективности применения полярных кодов для широкого класса моделей каналов. 2022.
- Экспериментальное исследование неортогонального множественного доступа PD-NOMA для сетей 6G. 2022. В отдельном подпроекте по повышению спектральной эффективности в 2022 году смоделировали системы связи для интернета вещей с PD-NOMA и SCMA. В 2023 году разработали модель PD-NOMA для связи с роботизированными устройствами и алгоритм выбора параметров кодовых книг SCMA.
- Разработка экспериментального макета многоканальной системы связи с неортогональным множественным доступом. 2021.
- Концепция и структура программного комплекса для формирования и анализа сигналов 5G NR (2021). Руководитель — Яков Крюков.

- Разработка модели канала связи с реконфигурируемой интеллектуальной поверхностью. 2023-2025.
- Разработка алгоритмов канального кодирования для систем связи 5G NR. 2023-2025.

## У.М.Н.И.К.

- Разработка интеллектуальной программной системы определения параметров цифровых сигналов на основе методов машинного обучения. 2026–2027.
- Разработка программно-аппаратного комплекса ReCK-RIS для управления реконфигурируемой метаповерхностью. 2026–2027.
- Разработка реконфигурируемой интеллектуальной поверхности. 2024-2025.
- Программное обеспечение для адаптивных LDPC и полярных кодеков (2022–2024). Руководитель — Георгий Шалин.

## Хозяйственные договоры

- Сотрудничество со Сколтехом в 2019–2021 годах. В 2019 году разработали алгоритмы формирования и обработки сверхузкополосных сигналов Open UNB. В 2020–2021 годах оценили число обслуживаемых абонентов при ограниченных вычислительных ресурсах и рассчитали пропускную способность каналов сети 5G с открытой архитектурой. Применили машинное обучение для моделирования радиоканала сверхнадёжной связи с малой задержкой (URLLC) и разработали модель случайного доступа для оценки коллизий при массовом подключении устройств.
- Сотрудничество с АО НПФ «Микран» в 2024 году по направлению разработки программного обеспечения и алгоритмов обработки сигналов для модемов радиорелейных линий связи.
