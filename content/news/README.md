# Новости лаборатории

Добавляйте записи в `ru.md` и соответствующие переводы в `en.md`.
Каждая запись начинается с заголовка `##`, далее дата в формате `YYYY-MM-DD`, направления и текст.

```md
## Заголовок новости

Дата: YYYY-MM-DD
Направления: wireless, access

Текст новости. Можно добавить [ссылку на результат](https://example.org/).
```

В английском файле используются поля `Date:` и `Directions:`.

Идентификаторы направлений:

- `wireless` — 5G/6G;
- `polar` — полярные коды;
- `access` — множественный доступ;
- `metasurfaces` — реконфигурируемые мета-поверхности.

Все записи появляются на главной, от новых к старым. Поле направлений может содержать несколько значений через запятую: такая новость появится на каждой указанной странице. Для общей новости лаборатории это поле можно пропустить. Сборка обнаруживает неизвестные направления.

После редактирования: `node tools/build-site.js`, затем `node tools/check-site.js`.
