# Локальный сайт лаборатории на Quarto

Самостоятельная версия с содержанием исходного сайта на русском и английском.
Источники страниц — `ru/*.qmd` и `en/*.qmd`. Стили — `styles.scss`, настройки — `_quarto.yml`.

Из этой папки:

```powershell
node home-sections.cjs
quarto render
quarto preview --host 127.0.0.1 --port 4321 --no-browser
```

Открыть http://127.0.0.1:4321/ru/index.html или http://127.0.0.1:4321/en/index.html.
Quarto 1.10.18 использован для первоначальной проверки. Python и R для сборки не требуются.

## Работа с материалами

Главная автоматически получает две записи библиографии из самого свежего года `publications.qmd` и до двух последних новостей из `news.qmd` соответствующего языка. Скрипт `home-sections.cjs` запускается Quarto перед сборкой; файлы `_home-sections.qmd` генерируются, их не нужно редактировать. Публикации сортируются по году, внутри года сохраняют порядок исходного списка (точные даты в источнике отсутствуют). Для сборки теперь также требуется Node.js.

- Редактировать `.qmd` напрямую; это Markdown с метаданными YAML.
- Переводы имеют одинаковые имена файлов в `ru/` и `en/`.
- Изображения и PDF находятся в `assets/`, ссылки из страниц начинаются с `../assets/`.
- Публикации перенесены без изменения библиографических записей. Конвертация в BibTeX не выполнялась.
- Профили сотрудников получили отдельные статические адреса `cv-kryukov.html` и `cv-pokamestov.html`.
- Новости на главной собираются из `news.qmd`. Упоминания новостей на страницах отдельных направлений пока редактируются вручную.
- Полнотекстовый поиск Quarto индексирует обе языковые версии.

`../tools/import-quarto.cjs` — одноразовый импорт из исходного Markdown. Обычная сборка его не вызывает; повторный запуск защищён от перезаписи QMD. `migration-manifest.json` фиксирует исходный коммит и объём перенесённых материалов.

Новая версия публикуется рядом с прежней; переключатель оформления позволяет сравнивать их на сайте.

## Главная: локальный дизайн без фотографий

Все страницы RU/EN используют общие `home.css`, `site.css` и `home-theme.js`. Светлая, тёмная и системная темы переключаются кнопками в шапке; предпочтение хранится в localStorage (`lab-theme`) и сохраняется при переходе между страницами и RU/EN. Шапка и подвал редактируются в `site-header-ru.html`, `site-header-en.html`, `site-footer-ru.html` и `site-footer-en.html`. Общая шапка содержит поиск по сайту; переключение языка открывает соответствующую страницу и сохраняет параметры фильтра.

`home-sections.cjs` собирает два примера публикаций из самого свежего года архива и до двух новостей с самыми поздними датами. Порядок публикаций внутри года соответствует исходной библиографии; точные даты публикации не предполагаются. Направления и вводный текст редактируются в главных QMD. На главной нет фотографий: единственное растровое изображение — существующий логотип; декоративная графика выполнена в SVG.

Workflow GitHub Pages собирает прежнее и новое оформление в один сайт.

## Общая тема внутренних страниц

`site.css` задаёт общие цвета, заголовки, карточки, формы, оглавление и поисковую выдачу; `styles.scss` сохраняет специализированные сетки исследований, команды и обучения. Цвета обеих тем определены в `home.css`.

`theme-diagrams.cjs` создаёт светлые и тёмные версии восьми исследовательских SVG из оригиналов в `assets/research/`. Геометрия, текст и обозначения сохраняются; сгенерированные файлы `*-light.svg` и `*-dark.svg` не редактируются вручную. Скрипт выполняется перед сборкой, а `home-theme.js` выбирает соответствующее изображение при смене темы. Фотографии не перекрашиваются.

Сборка: `quarto render`. Для просмотра готовой сборки без пересборки: `python -m http.server 4321 --bind 127.0.0.1 --directory _site`, затем `http://127.0.0.1:4321/ru/`. Публикация этими командами не выполняется.

## Сравнение оформлений на сайте

GitHub Pages собирает обе версии: прежнее оформление остаётся в `themes-preview/journal/`, новое доступно в `themes-preview/modern/ru/` и `themes-preview/modern/en/`. Вверху каждой версии есть переключатель оформления, по возможности сохраняющий страницу и язык. У старой версии нет отдельных опубликованных страниц новостей и медиа: для них переключатель ведёт на главную с новостями и на раздел исследований соответственно.

Сборка для публикации из корня: `node tools/build-site.js`, затем `node quarto-site/home-sections.cjs`, `quarto render quarto-site`, `node tools/build-comparison.js`, `node tools/check-site.js`, `node tools/check-comparison.js`. Папка `_site` в корне содержит полный публикуемый результат. Исходные материалы старой версии сохраняются в `content/`, новой — в `quarto-site/`.
