# Scientific / Научная

Третье независимое оформление сайта лаборатории № 317 ТУСУР. Адреса готовой сборки: `/themes-preview/scientific/ru/` и `/themes-preview/scientific/en/`. Прежние адреса и вариант по умолчанию сохранены.

## Сборка и просмотр

Из корня репозитория:

```powershell
node tools/project.cjs validate
node tools/project.cjs preview
```

Открыть `http://127.0.0.1:4321/themes-preview/scientific/ru/`. Обычный `dev` по-прежнему предназначен для Modern. После правки Scientific повторить `build`; `preview` показывает готовые файлы. Никакие из этих команд не публикуют сайт и не обращаются к Scholar.

## Исходники

| Файл | Назначение |
| --- | --- |
| `_quarto.yml` | Отдельная конфигурация Quarto и поискового индекса |
| `prepare.cjs` | Общая шапка и подвал, главная, сетка направлений, портфолио, подготовка всех 17 страниц каждого языка |
| `portfolio.cjs` | Краткие описания пяти выбранных работ с указанием источника; полный архив сюда не переносится |
| `scientific.css` | Палитры, типографика и адаптивная вёрстка только Scientific |
| `scientific.js` | Цветовая тема, меню, ссылки между версиями, архив, увеличение схем и сохранение фильтров |
| `diagrams.cjs` | Оригинальные SVG: RSMA, MIMO, RIS, полярные коды, QAM, общая топология |
| `DIAGRAMS.md` | Принципы, источники и ограничения научных схем |
| `../tools/check-scientific.cjs` | Проверка полного набора страниц, точности переноса записей и изоляции ресурсов |
| `../tools/test-scientific-diagrams.cjs` | Независимая матричная проверка полярной сети и обратного поворота QAM по координатам SVG |

Научные тексты и сведения о сотрудниках берутся из `../quarto-site/{ru,en}/*.qmd`, изображения — из `../quarto-site/assets/`. Библиография, персональные страницы, образование, новости и патенты включаются без изменения содержимого. Архив проектов сохраняет все записи, периоды, номера и ссылки; меняются только оформление раскрывающихся разделов и их идентификаторы. Главная автоматически получает последние записи из архива публикаций и страницы новостей; порядок внутри года остаётся исходным.

`prepare.cjs` создаёт `.generated/` с самостоятельной конфигурацией Quarto. Затем штатная команда `build` собирает этот проект и `tools/build-comparison.js` копирует его результат в общий `_site/`. CSS и JavaScript Scientific не подключаются к прежним версиям. Исходники Modern и прежнего оформления получают только дополнительный пункт переключателя; их стили не меняются. Workflow GitHub Pages менять не требуется: он уже вызывает общий `build`.

## Навигация и поведение

- Переключатель содержит существующие «Прежнее / Classic», «Новое / New» и новый пункт «Научная / Scientific».
- Modern ↔ Scientific сохраняют страницу и язык. Профили `cv-kryukov` и `cv-pokamestov` соответствуют параметру `person` в прежнем оформлении. Для новостей прежнего оформления используется главная с `#section-news`, для схем — раздел исследований.
- Языковые ссылки Scientific ведут на ту же страницу и сохраняют параметры. Фильтр публикаций использует существующий `navigation.html`; Scientific дополнительно сохраняет запрос и год в URL. Отдельные скрипты прежних версий не меняют своё прежнее поведение фильтров.
- Цветовая тема использует прежний ключ `lab-theme` со значениями `light`, `dark`, `system`. При недоступном хранилище используется память текущей страницы.
- Содержание и раскрывающийся архив доступны без JavaScript. На телефонах меню открывается кнопкой; Escape закрывает его. Схемы можно увеличить в доступном диалоге; Escape закрывает окно и возвращает фокус.
- Схемы на мобильных экранах упрощены для читаемости. Полная схема доступна отдельно. В RSMA можно выделить общий или приватные потоки; это подсветка, не имитация передачи.
- Движение не требуется для чтения. Учитывается `prefers-reduced-motion`; нет автоматических бесконечных анимаций.

## Достоверность материалов

Фотография RIS взята из существующего раздела `research-metasurfaces`: `assets/research/ris/anechoic-chamber-prototype.jpg`. На ней 16-элементная поверхность в измерительном стенде. В подписи есть ссылка на исходный раздел. Автор фотографии и дата съёмки не добавлялись: в материалах они не указаны.

SVG объясняют принципы работы и не являются измерениями. Созвездие 16-QAM — синтетический пример постоянного фазового поворота без шума. Замороженные позиции полярного кода показаны для пояснения, а не как оптимальная конструкция. Для портфолио используются только сведения существующих страниц; характеристик неописанных устройств и численных выигрышей нет. [Научные основания схем](DIAGRAMS.md).

## Проверки

`validate` выполняет существующие 23 теста без сети, математические проверки схем, сборку обоих проектов Quarto, проверки страниц и ссылок трёх оформлений, а также проверки Scientific. Последние сравнивают записи проектов и неизменяемые тексты с исходниками, проверяют языковые пары, уникальность идентификаторов и отсутствие подключения стилей Scientific к Modern. Математический тест извлекает соединения из SVG и сравнивает обе полярные сети с независимо построенной матрицей на 512 входах; для двух видов QAM проверяет 32 обратных поворота.

Браузерные снимки и разовые отчёты хранятся в `codex/`, не публикуются и не являются исходниками. При изменениях интерфейса проверяйте обе локализации, светлую и тёмную темы, фильтры публикаций, переключатели оформления и ширины 320, 390, 768 и 1440 px.
