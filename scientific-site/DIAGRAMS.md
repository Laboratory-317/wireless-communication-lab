# Научные иллюстрации Scientific

`diagrams.cjs` создаёт оригинальные векторные схемы, разработанные для этой темы. Это пояснения принципов работы, а не фотографии устройств и не результаты экспериментов лаборатории. Численные показатели BER, BLER, эффективности и выигрыша не используются.

```js
const { renderDiagram } = require('./diagrams.cjs');
renderDiagram('access', 'ru', 'expanded', 'research-access');
```

- Виды: `hero`, `access`, `mimo`, `ris`, `polar`, `dsp`.
- Языки: `ru`, `en`; варианты: `compact`, `expanded`.
- Результат: строка с самостоятельным inline SVG, `viewBox="0 0 760 470"`, доступными `title` и `desc`.
- Передавайте **уникальный `idPrefix` для каждого экземпляра на странице**: он входит в идентификаторы описаний и маркера стрелки. Одинаковые аргументы дают одинаковый SVG.
- Палитра наследуется через `--sc-ink`, `--sc-accent`, `--sc-muted`, `--sc-line`, `--sc-paper`, `--sc-surface`. Запасные значения соответствуют светлой теме. Тёмная тема задаёт эти же переменные на родительском элементе.
- Схемы не загружают внешние файлы, библиотеки, шрифты или сценарии. В `expanded` добавлены поясняющие подписи. Содержательное объяснение следует сохранять также в обычном тексте страницы.
- `data-sc-flow="common|private"` у RSMA и `data-sc-phase` у ячеек RIS позволяют подсвечивать части схемы. Автоматических анимаций нет. Принудительное уменьшение движения задано и внутри SVG.

## Узкие экраны

При ширине окна до 620 px включается отдельная группа `.sc-mobile`. Это новая компактная композиция, а не уменьшенная настольная схема. Подписи имеют размер 40–52 единицы: при ширине SVG 244 px основной текст получается 12,8 px. Увеличены толщина линий, точки созвездия и элементы схем. Полные группы `.sc-desktop` при этом скрыты.

- RSMA показывает типовой приёмник `k`: общий поток → SIC → свой приватный; чужие приватные потоки остаются помехой. Подробная схема сохраняет оба приёмника.
- MIMO сохраняет два входных потока, прекодер, решётку, два канала и два терминала.
- RIS сохраняет решётку, фазовые состояния, направления падающего и отражённого сигнала, передатчик и приёмник; поверхность явно обозначена пассивной.
- Полярная схема сохраняет все восемь линий, три ступени и двенадцать XOR. Убраны только номера строк и пример замороженных позиций; преобразование осталось `F^(⊗3)`.
- QAM сохраняет все 16 точек каждого созвездия, одинаковый поворот 20° и подписи «До» / «После».
- Главная схема сохраняет два терминала, прямые пути и дополнительный путь через RIS.

Атрибут `data-sc-detail="full"` на SVG принудительно показывает полную настольную схему при любой ширине окна. Он предназначен для доступного увеличения в диалоговом окне. Идентификаторы при копировании SVG в диалог нужно менять, чтобы на странице не появлялись дубли.

## Содержание и границы моделей

| Вид | Что изображено | Что не следует из схемы |
| --- | --- | --- |
| `access` | Нисходящая одноуровневая RSMA для двух пользователей: суперпозиция `p_c s_c + p_1 s_1 + p_2 s_2`; у каждого приёмника общий поток → SIC → свой приватный. | Это не универсальная схема NOMA или SCMA. Общий поток несёт части пользовательских сообщений, а не обязательно общее содержимое. SIC вычитает восстановленный вклад общего потока, чужой приватный остаётся помехой. |
| `mimo` | Линейное прекодирование `x = Ps`, антенная решётка, два вектора канала и `y_k = h_k^H x + n_k`. | Закрашенные области — условные направления передачи, не вычисленные диаграммы направленности. Межпользовательские помехи не объявлены нулевыми. |
| `ris` | Пассивная отражающая плоская решётка, падающий и отражённый пути, фазовые состояния элементов. Узкополосная диагональная модель `Φ = diag(β_n exp(jφ_n))`, `0 ≤ β_n ≤ 1`. | Это упрощение без расчёта взаимной связи элементов и потерь. Поверхность не усиливает сигнал и не создаёт собственный поток данных. |
| `polar` | Точная сеть `x = u F^(⊗3)` над GF(2), `F = [[1,0],[1,1]]`. Ступени с расстояниями 1, 2, 4, естественный порядок входа и выхода, без битовой перестановки. | Позиции `{0,1,2,4}` заморожены только для пояснения. Это не оптимизированная под канал конструкция. Пересечения линий без точки не являются соединениями. |
| `dsp` | Детерминированное 16-QAM из уровней `{−3,−1,1,3}`, повёрнутое на 20°, и его идеальная обратная ротация. | Без шума, частотного смещения и ошибок оценки. Это синтетическая иллюстрация, не измерения, не оценка качества алгоритма. |
| `hero` | Топология многопользовательской нисходящей связи: антенная решётка, прямые пути к двум терминалам, дополнительный отражённый путь через RIS. | Линии обозначают каналы связи, не рассчитанные траектории в конкретной среде. Не заявлены характеристики реальной установки. |

## Основания

Геометрия и композиция созданы заново. Источники использованы для проверки принципов, без копирования рисунков.

- RSMA: [Clerckx et al., A Primer on Rate-Splitting Multiple Access](https://arxiv.org/html/2209.00491v2), разделы III-A и IV-A: общий поток декодируется первым, затем его вклад удаляется перед декодированием приватного.
- Полярное преобразование: [Arıkan, Channel polarization](https://arxiv.org/html/0807.3917v5), разделы II и VII. На схеме показана только тензорная сеть `F^(⊗3)`; перестановка `B_N` из принятой в статье записи `G_N` не включена, что явно подписано.
- Пассивная RIS: [Wu and Zhang, Intelligent Reflecting Surface Enhanced Wireless Network via Joint Active and Passive Beamforming](https://arxiv.org/abs/1810.03961). Использована концепция управляемого пассивного отражения и диагональных коэффициентов элементов.
- MIMO и комплексное представление сигнала: [Tse and Viswanath, Fundamentals of Wireless Communication](https://web.stanford.edu/~dntse/wireless_book.html), главы 2, 7, 10. Сигнальное созвездие рассчитано непосредственно по комплексному повороту, без заимствования данных.

## Выполненная проверка

- `node --check scientific-site/diagrams.cjs`.
- Все 24 сочетания вида, языка и размера разобраны стандартным XML-парсером; идентификаторы уникальны при разных префиксах, `NaN` и неопределённых значений нет.
- Соединения извлечены из готового SVG полярного преобразования. Для всех 256 входных двоичных векторов результат сети совпадает с независимо построенной матрицей `F^(⊗3)`.
- Все 16 пар точек QAM проверены обратным комплексным поворотом с допуском 0,001 координатной единицы, учитывающим округление SVG.
- Графика проверяется в браузере вместе со страницами Scientific; локальные снимки находятся в `codex/scientific-qa/`.

После добавления мобильных композиций матричная проверка и обратный поворот повторены отдельно для обеих групп. Проверка для Node.js работает без сторонних пакетов: читает координаты из готовых SVG, а эталонную матрицу строит независимо через произведение Кронекера.
